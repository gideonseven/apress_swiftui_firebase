<h1>SwiftUI + Firebase Learning Project</h1>

A hands-on project inspired by the book Build Mobile Apps with SwiftUI and Firebase.
This repository contains small apps and exercises that helped me learn how to build modern iOS apps using SwiftUI and connect them to Firebase.

<h2>The Project</h2>

This project is my personal learning journey.
Each chapter of the book focuses on a different feature, and I follow along to understand how things work in real code:

<ul>
<li>Building clean and simple SwiftUI interfaces
<li>Managing app state the SwiftUI way
<li>Adding Firebase to an iOS project
<li>Authentication (email/password, etc.)
<li>Saving and retrieving data using Firestore
<li>Working with Firebase Storage
<li>Building small functional sample apps
<li>Understanding best practices while coding
<li>Everything is written in a beginner-friendly style, but still teaches solid, real-world concepts.
</ul>

<h2>Tech Stack</h2>

<ul>
<li>SwiftUI for the UI
<li>Firebase Authentication
<li>Firebase Firestore
<li>Firebase Storage
<li>Xcode (latest recommended version)
</ul>

<h2>How to Run This Project</h2>
<ul>
<li>Clone the repository
<li>Open the .xcodeproj or .xcworkspace file
<li>Add your own GoogleService-Info.plist
<li>Run the project on the simulator or on your device
</ul>

<h2>Lesson Learn</h2>
* How to structure SwiftUI apps
* How Firebase works behind the scenes
* How to connect UI + backend cleanly
* How modern iOS development tools fit together
* This project is helping me slowly build confidence in SwiftUI and backend integration.

<h2>Notes</h2>
<h3> This is not a polished production app.
It's a learning sandbox where I experiment, break things, fix them, and understand how everything works step-by-step.</h4>
<h3> Firebase will not work without adding your own <b>GoogleService-Info.plist</b> file.
